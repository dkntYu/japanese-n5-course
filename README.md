# 日日日本語｜N5 學習室

給已會五十音的自學者使用的日語 N5 課程，包含30堂教材、800詞、110字、練習、M1–M6單元測驗，以及期末A／B原創模考。

## 直接開始

網站發布後，請直接開啟：

https://dkntyu.github.io/japanese-n5-course/

不需要GitHub帳號，不需要下載或安裝。學習進度保存在目前瀏覽器；更換裝置或瀏覽器前，請先在網站側欄匯出進度備份。

期末A／B各有67題，已開放三科分時計時的瀏覽器合成語音模考。聽力與全站練習共用網站頂端的「日語聲音」及「語速」設定；只有成功播放才計為完成。

建議使用Microsoft Edge，並選擇Microsoft七海或圭太Online (Natural)。不同裝置可用的聲音可能不同；這些是瀏覽器合成語音，不是固定官方音檔，教材估分也不是正式JLPT成績。
